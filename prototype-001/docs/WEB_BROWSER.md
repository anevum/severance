# First WebGL 2 build — private engineering review

The Godot project has a Web preset using the Compatibility renderer, GDScript, and single-threaded WebAssembly. The Web build is generated by a dedicated GitHub Actions workflow on the game branch. That workflow only uploads a *review-only artifact*; it makes no Cloudflare calls and never changes ANEVUM production.

## Running the artifact locally

Download the successful workflow's `severance-prototype-001-webgl2-review` archive and extract it to a directory. Serve the folder over HTTP, for example:

    python3 -m http.server 8173 --directory path/to/exported-folder

Then navigate to http://localhost:8173 in a desktop browser with WebGL 2 support. Open the SOLO TEST to inspect the level. Browser WebSocket connections to localhost require a separate running Godot dedicated server; do not point them at the ANEVUM website.

Do not open index.html directly from the filesystem: WebAssembly package loading requires an HTTP server.

## Limitations

- This is an unoptimized developer build, without touch controls, accounts, voice chat, combat weapons or polished art.
- Chrome and Safari visual acceptance, real iPhone testing and secure WSS remote networking are not yet verified. A successful export test establishes only packaging.
- Public access and a game launcher remain disabled.
- No live Cloudflare account resources, account data or production domains are accessed by the build pipeline.
