# Changelog

## V0.3 - 2026-10-29

- Added transactional V0.3 schema revision registry without changing legacy `PRAGMA user_version=2` compatibility tests.
- Added hash-bound `__v=3` event payload tags for newly introduced event types while freezing old ledger event formats.
- Added scheduled medical deadlines with ordered, idempotent execution, cancellation, conditional skip and crash rollback.
- Added clinical subject linkage, revocable/expiring scoped evidence-read grants and a recorded access trail (synthetic only).
- Added multi-stop physical convoy movement, per-hop locations/ETA/fuel, bounded reroutes, and final-only stock credit.
- Added 40 V0.3 tests on top of the unmodified 85 V0.2 tests (125 total); stress trials and independent hash-replay checks.
- No public website, game client, Godot branch, managed server, database or canonical literary wiki changes.

## V0.2 - 2026-10-29

- Extends, does not replace, the original V0.1 World-State Laboratory.
- Preserves all 43 baseline tests, 64-event original JSONL trace and original SQLite demo fixture.
- Adds a time-limited medical case, locally supplied stabilization, escorted multi-hop transport, hospital recovery and finality after death.
- Adds registered depots, region hubs, physical carrier state, cargo capacity, fuel and refueling, delivery ETAs and empty carrier return journeys.
- Adds a verified alternate delivery route around blocked Crown Valley bridge, with extra fuel and delay.
- Adds regional supply deliveries and adjustable fictional aggregate production.
- Disallows instant V0.1 abstract stock transfers between separate registered depots.
- Records atomic transactions and event hash-chained replay under additive SQLite schema version 2.
- 42 new tests, bringing the total to 85, plus a deterministic 300-round seeded stress test and 76-event integrated story demonstration.
- No game engine, browser deployment, server, paid-hosting changes or official literary canon promotion.
